MINI RAMP - a tiny pixel-art skate game
=======================================

HOW TO PLAY LOCALLY
  1. Unzip this folder anywhere.
  2. Double-click index.html (opens in Chrome, Edge, Firefox, Safari).
  No server or install needed. Everything is inside index.html.

CONTROLS
  Space / START ... open gear menu, then start the run
  Left / Right ..... pump on the ramp
  Up / Down ........ ride toward the back / front (only while rolling fast)
  Z grab, X kickflip, C 360 spin (in the air)
  A ................ rock stall at the coping
  Gear menu: Up/Down pick a row, Left/Right change the item

FILES
  index.html ............ the whole game (code + your character sprite embedded)
  assets/Player.png ..... your original character sprite (for reference/editing)
  assets/Player_Idle.png  your original idle animation (APNG)

NOTES
  - The pixel font "Press Start 2P" loads from Google Fonts. Offline, the game
    still works but uses a plain monospace font. To keep the pixel font offline,
    download Press Start 2P and install it on your computer.
  - Your gear choices and a custom background (BG IMAGE button) are saved in the
    browser's local storage on that computer.
  - To change the character, replace the sprite frames embedded in index.html
    (the B64 list) with your own 24x24 PNG frames, or ask me to do it.
